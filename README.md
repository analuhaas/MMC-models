2024 MATLAB license necessary. For previous versions contact the onwer.

## Features

This repository contains 3 simulations concerning 3 different models of the MMC:
- Simple model (models the arm with ideal voltage sources).
- Average model (models the arm with an equivalent capactiro approximation).
- Switching model (models each HB SM in detail).

The code param_allsim_20250429 must be run before performing simulations to obtain simulation parameters.

A report with further explanation of the models and some simulations results is also provided.
